# Development Setup

## Prerequisites

- Windows 11 + WSL2 (Ubuntu 24.04)
- Docker Desktop for Windows (must be running before any Docker command)
- Node.js (inside WSL or via the `portfolio-node-1` container)

## First-time setup

```bash
# 1. Clone the repo and enter the directory
cd /home/rodrigo/portfolio

# 2. Copy environment file and fill in values
cp .env.example .env

# 3. Start containers
docker compose up -d

# 4. Install PHP dependencies
docker exec portfolio-app-1 composer install

# 5. Generate app key
docker exec portfolio-app-1 php artisan key:generate

# 6. Run migrations
docker exec portfolio-app-1 php artisan migrate

# 7. Create storage symlink
docker exec portfolio-app-1 php artisan storage:link

# 8. Install JS dependencies and build assets
docker exec portfolio-node-1 npm install
docker exec portfolio-node-1 npm run build
# or for dev with HMR:
docker exec portfolio-node-1 npm run dev
```

## Required .env values

```
APP_KEY=           # generated by artisan key:generate
DB_PASSWORD=       # must match docker-compose.yml
GITHUB_TOKEN=      # GitHub PAT (classic), scope: public_repo — for GitHub stats sync
```

## After a WSL restart

Docker Desktop reconnects automatically, but nginx mounts may be stale:

```bash
docker compose up -d --force-recreate nginx
```

## Useful commands

```bash
# Run tests
docker exec portfolio-app-1 php artisan test

# Run a specific test file
docker exec portfolio-app-1 php artisan test tests/Feature/Admin/ProjectTest.php

# Tail application logs
docker exec portfolio-app-1 tail -f storage/logs/laravel.log

# Connect to MySQL
docker exec -it portfolio-mysql-1 mysql -u root -p portfolio
```

## Admin access

1. Register via `/register` (only the first user or via seeder)
2. Set up TOTP 2FA on first login
3. All admin routes are under `/admin`
